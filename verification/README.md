# Browser QA Evidence

This folder keeps a small set of useful QA references. It is not included in the deployed Pages artifact.

- `responsive-layout/width-audit.json` — horizontal-overflow audit at eight viewport widths.

Re-run `pnpm test`, `pnpm typecheck`, `pnpm i18n:check`, and `pnpm build` for current source validation; historic audit results are not a substitute for a live browser check.
